# Club Sphere

Club Sphere is a comprehensive web application designed to streamline the management of clubs, events, and memberships. It provides a seamless experience for administrators, club managers, and members to interact, organize, and participate in various club activities.

## 🎯 Project Purpose

The primary goal of Club Sphere is to facilitate efficient club management by offering tools for:
- **Administrators** to oversee the entire platform, manage users, and monitor payments.
- **Club Managers** to create and maintain clubs, organize events, and manage member registrations.
- **Members** to easily discover clubs, join communities, register for events, and track their participation and payments.

## ✨ Key Features

### 👤 User Roles & Dashboard
- **Admin Dashboard**:
  - **Manage Users**: View and manage all registered users.
  - **Manage Clubs**: Oversee all clubs created on the platform.
  - **Payments**: Track and view payment details across the system.
- **Manager Dashboard**:
  - **Club Management**: Create, edit, and manage club details.
  - **Event Management**: Create and edit events, view registrant lists.
  - **Member Oversight**: View and manage members within their clubs.
- **Member Dashboard**:
  - **My Clubs**: View joined clubs.
  - **My Events**: Track registered events.
  - **Payment History**: View personal transaction history.
  - **Profile Management**: Update personal details.

### 🌐 General Features
- **Authentication**: Secure Login and Registration system.
- **Club Discovery**: Browse and view details of available clubs.
- **Event Discovery**: Explore upcoming events and register.
- **Responsive Design**: Fully responsive UI for seamless usage on desktop and mobile devices.

## 🛠️ Technologies & Packages

This project leverages a modern tech stack to ensure performance and scalability:

- **Frontend Framework**: [React](https://react.dev/) (v19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **Routing**: [React Router](https://reactrouter.com/) (v7)
- **State Management & Data Fetching**: [@tanstack/react-query](https://tanstack.com/query/latest)
- **Backend / Auth**: [Firebase](https://firebase.google.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)
- **Charts**: [Recharts](https://recharts.org/) for data visualization.
- **Forms**: [React Hook Form](https://react-hook-form.com/)
- **Notifications**: [React Hot Toast](https://react-hot-toast.com/), [SweetAlert2](https://sweetalert2.github.io/)
- **HTTP Client**: [Axios](https://axios-http.com/)
